# sdk/

Shared, non-UI building blocks — deliberately kept outside `src/` so they
don't collide with the in-progress frontend work.

- **`golden-vector.json`** — generated by
  `contracts/scripts/printCommitmentVector.ts` from
  `AnemiaRegistry.hashScreeningCommitment` (the ground truth). Do not
  hand-edit; regenerate with `npm run vector` in `contracts/`.
- **`ts/`** — a standalone TypeScript/JavaScript package with the canonical
  `ANEMIASCAN_SCREENING_COMMITMENT_V1` builder (`commitment.mjs`) and a
  parity check against `golden-vector.json` (`verify.mjs`,
  `npm run verify`). When the frontend is ready to wire up `/proof` and
  `/verify` pages, import `commitment.mjs` directly rather than
  reimplementing the encoding a third time.

See [`../docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md) for the full
three-way (Solidity/Python/TypeScript) parity story.
